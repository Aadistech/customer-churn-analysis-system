System Architecture & Overview

5th-Semester Mini Project developed and architected by Aadibi.

Project Summary

The Customer Churn Analysis & Prediction System is an enterprise-grade web application designed to convert raw historical telecom telemetry data into actionable analytical insights and real-time machine learning predictions.

Core Architecture & Technology Stack

  • Developer / Architect: Aadibi
  • Backend & API: Python, Flask, Joblib
  • Machine Learning: Scikit-learn (Random Forest Classifier with class balancing)
  • Database Layer: SQL/MySQL via Pandas and SQLite storage
  • Data Analytics & Visualization: Pandas, NumPy, Matplotlib, Seaborn
  • Frontend Interface: HTML5, CSS3 (Enterprise Corporate Theme), JavaScript

Project Objectives

This software satisfies all academic requirements for the 5th-semester mini project by bridging Data Analytics, Relational Database Management, Machine Learning Classification, and Full-Stack Web Development into a unified, deployment-ready architecture.
